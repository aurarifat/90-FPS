### Installation Instructions
1. Download `90FPSBooster-v1.1.0.apk` to your Android device.
2. Tap the downloaded APK in your device's file manager or browser.
3. Allow "Install unknown apps" permission if prompted.
4. Launch **90 FPS BOOSTER**.
5. Connect Shizuku via Wireless Debugging (see built-in guide in Settings).
6. Tap **"Stabilize 90 FPS Now"** or configure your games.
